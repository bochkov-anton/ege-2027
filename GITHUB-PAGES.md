# Публикация «Мой ЕГЭ» через GitHub Pages

**Режим:** один Android-планшет, GitHub хранит только статические файлы. Прогресс, ошибки, результаты и заметки — локально на планшете.

## Принцип работы

GitHub-репозиторий — код интерфейса, данные учебного плана, JS/CSS, иконки. GitHub Pages публикует эти файлы по HTTPS. Приложение на планшете один раз загружает их, кэширует для автономной работы, а личные данные сохраняет локально в localStorage. Ученице не нужен аккаунт GitHub.

**Репозиторий:** https://github.com/bochkov-anton/ege-2027

**Действующий адрес GitHub Pages:** https://bochkov-anton.github.io/ege-2027/ .

## Первичная публикация

1. Войдите в GitHub под своим аккаунтом. Создайте отдельный **публичный** репозиторий, например ege-2027. На бесплатном тарифе GitHub Pages работает с публичным репозиторием.
2. Загрузите на ветку main **содержимое** пакета ege-2027-android-pwa.zip, а не ZIP как один файл. В корне должны быть index.html, manifest.webmanifest, sw.js, JS и CSS. Иконки — в папке icons. Файл .nojekyll также должен лежать в корне.
3. В репозитории откройте Settings → Pages → Build and deployment → Source → Deploy from a branch. Выберите main и /(root), нажмите Save.
4. Дождитесь публикации, откройте ссылку HTTPS, проверьте экран «Сегодня».
5. На Android-планшете в Chrome откройте этот адрес и выберите в меню ⋮ → «Установить приложение» / «Установить и создать ярлык».
6. Проверьте без интернета: откройте несколько разделов онлайн, затем отключите Wi-Fi и убедитесь, что план доступен. Внешние PDF и видео требуют интернета.

## Публикация без ноутбука

В Android Chrome можно включить «Версия для ПК», распаковать ZIP через «Файлы» и добавить файлы через GitHub → Add file → Upload files. Внимание: нужно сохранить структуру подпапки icons. Если с Android это неудобно, создайте только пустой публичный репозиторий и передайте точное имя OWNER/REPO в чат с подключённым GitHub — после этого исходные файлы можно записать через API без ноутбука.

На GitHub не нужно хранить резервные копии, личные документы или заметки: сайт публичный. Прогресс не отправляется на GitHub.

## Обновления и безопасность данных

Обновляйте исходные файлы в том же репозитории — адрес сайта должен остаться неизменным. GitHub Pages публикует коммиты, PWA получает новые файлы при следующем открытии онлайн; иногда требуется повторный запуск. Версия офлайн-кэша меняется при сборке ZIP.

Не удаляйте данные приложения/Chrome и не переустанавливайте приложение без резервной копии. В «Ещё» доступен экспорт JSON; сохраняйте отдельную копию каждую пятницу.

## Уведомления

Таймер **не останавливается при закрытии карточки занятия**: сверху остаётся мини-панель, а время сохраняется локально с отметкой начала и восстанавливается после запуска. При возвращении PWA вычисляет прошедшее время по часам устройства. С разрешения Chrome возможны системные уведомления. После полного закрытия или принудительной выгрузки PWA Android не гарантирует своевременный фоновый сигнал. Для надёжного звука при закрытом приложении используйте стандартный таймер Android.
