# Установка «Мой ЕГЭ» на Android-планшет — без ноутбука

**Предпочтительный вариант теперь GitHub Pages.** См. [GITHUB-PAGES.md](./GITHUB-PAGES.md). Ниже оставлены инструкции для альтернативного размещения ZIP на Netlify/Cloudflare.

Эта инструкция предназначена для ученицы, у которой **только Android-телефон и Android-планшет**. Никакого APK, Android Studio или Play Market не требуется.

## Кратко

1. Получить готовый архив **`ege-2027-android-pwa.zip`** (лежит в папке проекта CodexPro).
2. Разместить архив один раз на HTTPS-хостинге (например, [Netlify Drop](https://app.netlify.com/drop) или [Cloudflare Pages Direct Upload](https://developers.cloudflare.com/pages/get-started/direct-upload/)). Ссылку сохранять минимум до ЕГЭ-2027.
3. Открыть готовый **HTTPS-адрес** в Google Chrome на планшете.
4. Chrome **⋮ → Установить приложение** (либо **Установить и создать ярлык**) → подтвердить.
5. Открыть приложение с иконки **«Мой ЕГЭ»**. При наличии интернета первый раз перейти по основным разделам; затем можно отключить сеть и проверить работу.

> Пока приложение не размещено на HTTPS-сайте, его нельзя надёжно установить как PWA. Простое открытие файла `index.html` или отправка HTML в Telegram этого не заменяют.

## Как опубликовать ZIP только с планшета

### Вариант А. Netlify Drop — проще для первого запуска

1. На планшете откройте [app.netlify.com/drop](https://app.netlify.com/drop) через Chrome.
2. Выберите **Browse files / Выбрать файлы** и загрузите архив `ege-2027-android-pwa.zip` из «Загрузок». Netlify принимает ZIP-файлы.
3. Дождитесь выдачи HTTPS-адреса; откройте его и убедитесь, что показана страница «Сегодня».
4. **Создайте бесплатную учётную запись Netlify**, чтобы сайт и ссылка управлялись вами; не опирайтесь на временную анонимную публикацию в течение полугода.
5. Сохраните точный HTTPS-адрес и отправьте его на телефон (например, через мессенджер).
6. На каждом устройстве: Chrome → адрес → ⋮ → «Установить приложение».

Если загрузка архива не предлагается в мобильном интерфейсе, откройте в Chrome меню ⋮ → **Версия для ПК**. Это способ отображения страницы, не компьютер.

### Вариант Б. Cloudflare Pages

1. В браузере планшета откройте [Cloudflare Dashboard](https://dash.cloudflare.com/), войдите/зарегистрируйтесь.
2. Перейдите в **Workers & Pages → Create application → Pages → Direct Upload / Drag and drop**.
3. Создайте проект и выберите готовый ZIP из «Загрузок».
4. Опубликуйте. Полученный адрес будет иметь вид `https://<имя-проекта>.pages.dev` (имя не фиксируется в этом документе).
5. Откройте адрес через Chrome и установите на главный экран.

Cloudflare Pages поддерживает загрузку ZIP-файла в режиме drag-and-drop. Надписи в интерфейсе могут незначительно отличаться.

### Что остаётся публичным?

При публикации доступны **статические учебные материалы приложения**: код интерфейса, названия тем и ссылки на внешние ресурсы. **Личные отметки, заметки и результаты не публикуются** — приложение хранит их в памяти браузера конкретного устройства (`localStorage`). Не включайте в ZIP экспорт прогресса или личные документы.

## Планшет + телефон

**Рекомендуем выбрать планшет основным устройством**: на нём удобнее решать задачи, смотреть схемы и вносить записи. Телефон можно использовать для просмотра сегодняшних занятий.

На двух устройствах будут **разные независимые состояния**. Для переноса:

1. На исходном устройстве откройте **Ещё → Поделиться резервной копией**. Если Android не предлагает прямую передачу файла, он сохранится в «Загрузках».
2. Отправьте `ege-2027-progress-YYYY-MM-DD.json` на второе устройство удобным способом: Quick Share («Быстрая отправка»), собственный облачный диск или пересылка себе.
3. На принимающем устройстве откройте **Ещё → Импортировать файл JSON**, выберите файл в системном окне Android.
4. Подтвердите **замену** прогресса. Это не слияние изменений: более старая копия может затереть новую.

Если использовать оба устройства для активного внесения отметок в один день, данные **не объединятся автоматически**. Самый безопасный вариант — вести прогресс на планшете и переносить резервную копию на телефон только при необходимости.

## Что работает без сети

**После успешной загрузки и установки:** ежедневный и недельный планы, карточки тем, заметки, отметки, учёт ошибок, таймер, поиск, повторения, локальные пользовательские ссылки (само открытие внешних URL потребует сети).

**Только онлайн:** веб-страницы ФИПИ, внешние видео, интерактивные банки заданий, онлайн-PDF (если файлы заранее не сохранены на устройстве).

## Важно о хранении и обновлениях

- Не очищайте **данные сайта / Chrome** и не удаляйте установленное приложение, пока не сделали резервную копию.
- Еженедельно делайте резервную копию (лучше по пятницам).
- В Chrome и установленной PWA на **одном HTTPS-адресе** обычно используется одно происхождение (origin); смена адреса или домена создаёт отдельное хранилище.
- Смена `http`/ `https`, браузера или хостинга может привести к появлению пустой копии. Перенесите JSON.
- Переустановка/обновление сайта может изменить кэш. Пользовательские отметки отдельно от него, но резервную копию всё равно стоит держать.
- В режиме инкогнито и при очистке данных сайта полугодовой прогресс может не сохраниться.

## Для того, кто обновляет программу

В CodexPro workspace `learning`, каталог `ege-2027-planner`:

```bash
node scripts/build-icons.mjs
python3 scripts/package-site.py
node --test tests/*.test.mjs
```

Пересоберите ZIP и повторно загрузите **на тот же HTTPS-сайт**, не меняя адрес. Скрипт упаковки автоматически присваивает новому набору файлов версию офлайн-кэша; вручную менять `sw.js` не нужно. После публикации закройте установленное приложение и откройте его снова при наличии интернета, чтобы Chrome получил обновление.
