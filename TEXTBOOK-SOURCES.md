# Учебники для ЕГЭ-2027 — библиотека и правила использования

Учебный маршрут состоит из трёх частей: **Фоксфорд** — кратко разобраться, **учебник** — изучить теорию полно, **РЕШУ ЕГЭ** — решить конкретные задания. Официальные документы ФИПИ не заменяют теоретический учебник.

## Использование на Android-планшете

На вкладке «Теория: Фоксфорд + учебник» для каждой темы предлагаются **два источника**: основной и дополнительный. Читать оба полностью **не нужно** — выберите один. Отображаются авторы, класс, уровень, тематический ориентир, что именно надо найти, ссылка издателя, поиск учебника в Яндексе и поиск раздела.

Номер параграфа/страницы без точного оглавления конкретной редакции **не подставляется**: `paragraph=null`, `pages=null`, `sectionStatus=topic_hint_unverified`. После проверки оглавления можно ввести свой параграф и страницы. Эта запись хранится локально на планшете и включается в экспорт JSON; она не публикуется на GitHub.

## Достоверность и ограничения

Ссылки на страницы издателя — идентификация издания и информация о покупке/ЭФУ, **не обещание бесплатной загрузки**. Некоторые страницы требуют авторизацию или отвечают HTTP 403 автоматическим проверяющим системам. На каждой карточке предусмотрен поиск в Яндексе; в поисковом запросе указано «скачать легально» и «оглавление». Сомнительные пиратские PDF в приложение не включены.

Для всех 234 учебных карточек назначаются два издания по предмету и теме. Это **семантическое сопоставление**, а не подтверждение главы или страницы: точные параграфы можно добавлять лишь после проверки оглавления выбранной редакции. Состав учебных планов и содержимое внешних сайтов может меняться; ссылки нужно проверять на настоящем Android-планшете.

Никогда не отправлять записи ученицы или экспорт JSON в публичный репозиторий.
