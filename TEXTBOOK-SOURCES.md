# Учебники для ЕГЭ‑2027 — библиотека и правила подбора

## Задача

**Не путать три разных слоя.** Фоксфорд — быстрый ввод в тему и отдельные объяснения. Учебник — основная систематическая теория (один выбранный, необязательно два одновременно). РЕШУ ЕГЭ — практика на странице с задачами. Кодификаторы ФИПИ — описание экзамена, **не учебник**.

В личной карточке темы показываются:
- основной и дополнительный учебник, авторы, класс, уровень, идентификатор издания при наличии;
- основной тематический ориентир в содержании **без выдуманного параграфа и страницы**;
- конкретные знания, которые надо найти в разделе, из `lesson-content.js`;
- **«Издатель / электронная версия»**, **«Найти учебник в Яндексе»** и **«Найти тему в учебнике»**;
- поле **«Мой параграф / страницы»**, привязанное к конкретной теме + книге, которое хранится в `state.textbookPlaces` в `localStorage`.

Книги могут быть платными, лицензируемыми или доступными только через предпросмотр. «Издатель» **не означает бесплатную загрузку**. Поиск в Яндексе предназначен для поиска законной электронной версии, каталога или бумажной книги; ссылки на сомнительные PDF-сканы не встроены.

## Как определяется «раздел» для конкретной темы

`textbooks.js` хранит несколько десятков **предметных тематических ориентиров**. Алгоритм выбирает основную и дополнительную книгу по предмету, типу темы (генетика, органика, геометрия, логарифмы и т.п.) и её месту в программе. Он показывает **тему для поиска в оглавлении**, а ниже — индивидуальный список знаний для этой темы.

**Статус ориентира:** `topic_hint_unverified`. Это семантическое соответствие, не проверенный номер главы в конкретной редакции. Поэтому поля `paragraph` и `pages` остаются `null`.

Когда ученица нашла нужный § и страницы в своей версии, она вводит их в поле. Приложение сохраняет только эту личную привязку и показывает её при следующем открытии. Экспорт/импорт JSON уже включает значение.

## Ограничения и следующий редакторский этап

1. Источники подтверждены каталогами издателя, но не все карточки каталога удалось открыть из проверяющего окружения из-за HTTP 403. Для каждого источника доступна запасная ссылка на поиск.
2. Параграфы и страницы нельзя заполнять массово без **подтверждённого оглавления точно выбранной версии учебника**. Сначала следует выбрать конкретное издание, сверить содержание и только затем массово проставлять номера.
3. Библиография для 234 тем получена тематическим сопоставлением. Требуется предметная экспертиза точности соответствия особенно для смешанных, диагностических и повторительных тем.
4. «Foxford → учебник → задачи» — три отдельных образовательных шага. Источники не дублируют друг друга. При желании можно заменить альтернативную книгу своим школьным учебником в будущем выпуске.
5. Учебники и издательские материалы принадлежат правообладателям; приложение хранит **метаданные и ссылки**, а не копии книг.
