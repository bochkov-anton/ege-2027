# Аудит согласованности ЕГЭ-2027: темы, зависимости, теория, задания

Дата: 9 октября 2026. Проект: `ege-2027-planner`, адрес публикации: https://bochkov-anton.github.io/ege-2027/.

## Обнаруженная причина

Изначальная привязка учебных URL к темам создавалась по совпадению слов и доступности HTTP-страниц. Такой способ **не проверяет предметное соответствие**: например, «методы биологии» ошибочно получали ссылку на «методы изучения клетки», молярные расчёты — на ОВР, а преобразования степеней и корней — на логарифмы.

Также исходный календарь имел несогласованные зависимости (например, отдельные реакции органики требовали ещё не изученных базовых разделов), а старая схема отдельно назначала теорию и практику в разные слоты, что делало 234 темы недостижимыми за 26 недель.

## Исправления смыслового соответствия

**Фоксфорд.** Отменена автоматическая привязка по регулярным выражениям и частичным совпадениям названий. Теперь тематическая статья показывается **только для конкретного идентификатора темы**, с редакционно выбранным адресом и пометкой `partial` при неполном охвате. Статьи по случайно совпавшим словам исключены. Отсутствие статьи честно отображается; остаются учебник и локальный конспект.

**РЕШУ ЕГЭ и внешняя практика.** `resource-integrity.js` проверяет семантическую совместимость темы и названия категории упражнений по предметной таксономии. Общие каталоги и отдельные линии не представляются полноценными пробными вариантами; частичные подборки обозначены как **часть темы**. Ни HTTP 200, ни совпадение пары общих слов не считается предметной верификацией.

Статистика на момент аудита:

| Метрика | Количество |
|---|---:|
| Учебные темы | 234 |
| Ранее автоматически назначенные URL задач | 402 |
| Оставлены как тематически подходящие по названию категории | 179 |
| Убраны из рекомендаций как неточные, слишком общие или неподтверждённые | 223 |
| Темы с хотя бы одной допустимой внешней подборкой | 132 |
| Темы без подходящей подтверждённой по заголовку подборки | 102 |
| Темы с конкретной статьёй Фоксфорда (включая частичные) | 47 |

**Ограничение:** 179 ссылок прошли проверку **по названию категории**, не ручную проверку текста каждой задачи. Поэтому в интерфейсе НЕ используется ложная надпись «каждое упражнение проверено». Прямые учебные задания, сформулированные в самой карточке, остаются доступны для всех 234 тем даже при отсутствии внешней ссылки. Нельзя считать 102 отсутствующие ссылки «исправленными» без подбора новой конкретной и содержательно точной страницы.

## Зависимости и 26-недельный маршрут

- `curriculum.js`: DAG из 234 тем, явные зависимости, стабильная топологическая сортировка, защита от занятия практикой до основ.
- Исходный календарь не объявляется обязательной предметной последовательностью; актуальный план строится по графу.
- До исправления симуляция на 130 будних дней с немедленным успешным выполнением каждого задания достигала **194/234 темы**.
- Новый план для **новых** дней назначает две темы по 75 минут, каждая содержит обе вкладки: теория → самостоятельная практика → сохранённый результат **не менее 80% при минимум трёх заданиях**. По необходимости отдельно отводится до 10 минут повторения.
- При идеальном, без пропусков прохождении симуляция достигла **234/234** за 130 учебных дней. Это *проверка пропускной способности*, а не гарантия успешного обучения за этот срок.
- Назначения ранее начатых дней и личные результаты остаются неизменными. `state.curriculumAssignments[day]` не переписывается задним числом.
- При перегрузке, недосыпе, школьном ДЗ или недостаточном освоении дневная программа сокращается. Дополнительные часы в выходные **не назначаются**.

## Сверка с ФИПИ

Официальный источник: https://fipi.ru/ege/demoversii-specifikacii-kodifikatory.

Для ЕГЭ-2027 ФИПИ публикует проекты демоверсий, спецификаций и кодификаторов. Файл `fipi-map.js` **не является скопированным кодификатором**: это редакционное соответствие 234 карточек широким областям содержания и явно названным линиям ЕГЭ. В коде это маркируется `status:draft`, `editorial_week_domain_only` или `declared_line_in_plan`. Из принадлежности к тематическому разделу ФИПИ **не следует**, что подобранная статья или задача проверена ФИПИ.

Исправлены ложные пересечения: клеточное дыхание не классифицируется как физиология человека; неорганические соединения не считаются органическими из-за вхождения подстроки. Последний шаг полной верификации по утверждённым кодификаторам, каждому элементу содержания и заданиям-2027 остаётся редакторским, не завершённым автоматически.

## Как воспроизвести проверки

```sh
node scripts/report-resource-integrity.mjs
node scripts/audit-resource-semantic.mjs
node scripts/simulate-curriculum.mjs
node --test tests/*.test.mjs
python3 scripts/package-site.py
node scripts/verify-live.mjs
```

Тесты `tests/resource-integrity.test.mjs` проверяют конкретные неверные соответствия, 234 карточки и запрет узких подборок для полных пробников. Тесты `tests/curriculum.test.mjs` проверяют граф, перенос недоделанных тем и сохранение старых данных.

## Оставшиеся содержательные задачи

1. Для **102 тем** без достаточно точных ссылок выполнить предметный поиск и **открыть реальные задачи**, а не просто проверить адрес или заголовок категории. При наличии нескольких поднавыков указать, какую часть покрывает каждый источник.
2. Для каждой из **234 тем** проверить согласование трёх компонентов: индивидуальная цель/теория → конкретный § учебника → набор задач. Не выдавать один раздел за весь смешанный урок.
3. Разобрать сложные/экзаменационные задания, где нужен именно полный демонстрационный вариант, а не одна тематическая категория; подтверждать конкретные задания по ФИПИ.
4. Провести полный ручной crosswalk 2027 кодификатора по элементам и периодически пересматривать его после выхода окончательной версии.
5. Проверить доступность Фоксфорда и тренировочных страниц на реальном Android-планшете. Автоматическая проверка с иного IP не гарантирует загрузку.
6. Улучшить методику освоения: 80% при трёх задачах — **порог минимального контроля в приложении**, а не валидированный психометрический стандарт или доказательство закрепления; требуется отсроченная проверка и различие сложности заданий.

Личные данные из браузера остаются локальными. При обновлении GitHub Pages **не очищайте данные PWA**.


## Первоисточники ФИПИ-2027: получены и сверены 9 октября 2026

Скачаны и проверены как ZIP-архивы официального сервера ФИПИ:

- Биология — https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/bi_11_2027.zip
- Химия — https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/hi_11_2027.zip
- Математика — https://doc.fipi.ru/ege/demoversii-specifikacii-kodifikatory/2027/ma_11_2027.zip (для маршрута выбран **профильный** вариант спецификации/демо)

Во всех трёх архивах присутствуют действительные PDF-проекты кодификаторов и спецификаций; из них извлечён машинный текст для сверки. В документах стоит пометка **«ПРОЕКТ»**. Полные PDF и их тексты **не размещаются в публичном учебном репозитории**.

Контрольные факты из «Раздела 2. Перечень элементов содержания»:

- Биология: код **1** — «Биология как наука. Живые системы и их изучение», коды **1.1–1.3** — состав биологических наук, свойства живого и методы исследований. Код **2.2** относится к химическому составу клетки. Поэтому `bio:1:0` охватывает **два разных элемента кодификатора**, а одна статья о клеточных методах не покрывает тему.
- Химия: **1.11** — концентрации растворов, **1.12** — окислительно-восстановительные реакции. Следовательно, приписывать тему о моле/молярной массе и стехиометрии ОВР из-за совпадения общих слов недопустимо.
- Математика: раздел **1** — «Числа и вычисления» (в том числе пункт **1.8** о преобразовании выражений), раздел **2** — «Уравнения и неравенства», раздел **3** — «Функции и графики». Урок о степенях/корнях нельзя подменять статьёй о логарифмах.

Сверка подтверждает необходимость раздельных кодов ФИПИ для **подтем**, а не одного кода для всей составной карточки. На данном этапе установлены достоверные опорные разделы, но **полное поэлементное экспертное соответствие всех 234 уроков каждой формулировке кодификатора ещё не завершено**. `fipi-map.js` маркирует текущий crosswalk как редакционный и не выдаёт его за сертифицированный ФИПИ.

Воспроизведение в защищённом рабочем пространстве: `scripts/download-fipi-2027.mjs`, `scripts/extract-fipi-text.py`, `scripts/list-fipi-content-codes.py`. Файлы `.cache-fipi-2027` остаются вне GitHub.

## Дополнительная адресная ревизия оглавлений и последовательности действий (9 октября 2026)

Сопоставлены названия отдельных составных уроков и **конкретные названия параграфов по ISBN** из `verified-tocs.js`. Исправления в `page-assignments.js`:

- `chem:1:2`: расчёты по уравнениям и газовые законы (§ 5–6 Ерёмина, 10 кл.) вместо параграфов об ОВР и структурной изомерии.
- `chem:4:2`: для альдегидов указан § 48 о свойствах карбонильных соединений; исключён § 9 о растворах.
- `chem:6:0`: добавлены разделы по азоту, углероду и кремнию, ранее отсутствовавшие в ссылках для широкой темы о неметаллах.
- `chem:8:1`: к ОВР добавлены реакции ионного обмена; `chem:9:0` и `chem:9:1` дополнены параграфами о реакциях углеводородов, а не только их строении.
- `bio:9:1`: добавлен § 8 о почках растений; `bio:11:0`: добавлен § 51 о хвощах и плаунах.
- `math:1:1`: начальные действия со степенями и корнями больше не ссылаются на § 4 по логарифмам 11-го класса.
- `math:2:2`: для случайных величин и распределений указаны §§ 18, 21–23 Мерзляка, 11 кл., вместо § 26 о методах решения уравнений.

Отметка «страницы проверены» означает **совпадение с оглавлением конкретного издания**, не подтверждает, что все подтемы содержатся в указанном разделе или что все задания книги соответствуют КИМ. Полный предметный crosswalk 234 составных карточек остаётся открытой работой.

В интегрированном занятии теперь теорию подтверждают **в теоретической вкладке** до открытия вкладки с заданиями; контрольные отметки выполняют по порядку, и результат практики нельзя записать до этапа самостоятельного решения. Дневные назначения, прошлые оценки и ключи прогресса не мигрируются и не удаляются. Новое поведение проверяется в `tests/ui-smoke.test.mjs` и `tests/verified-pages.test.mjs`.

После правки исходников перед публикацией обязателен запуск `python3 scripts/package-site.py` для синхронного обновления `sw.js` и PWA ZIP; локальная сборка **не означает** публикацию GitHub Pages.

## Поэлементный аудит учебных материалов

Отдельная повторная ревизия 9 октября 2026 выявила типовой дефект: составная тема могла иметь одну общую статью без покрытия остальных частей. Например, `chem:1:1` требует **химическую связь, кристаллические решётки и степени окисления**; статья о видах связи не заменяет ни § о решётках, ни алгоритм степеней окисления. Эта тема теперь содержит три специально подобранные статьи.

Для всех **234** тем введён список из суммарно **433** смысловых пунктов; **16** составных уроков имеют сверенные по содержанию аспекты, **218** требуют ручной сверки. Для **199** из **433** смысловых пунктов предложены кандидаты по совпадению заголовков; остальные **234** пока не имеют кандидатов. Это не свидетельствует о полном покрытии программ. В интерфейсе не подтверждённые компоненты обозначены прямо. Даже прошедшие проверку статьи не дают автоматического статуса верификации конкретных упражнений или § учебника. Подробная карта и процесс дальнейшей проверки: [CONTENT-COVERAGE-AUDIT-2027.md](./CONTENT-COVERAGE-AUDIT-2027.md), машинный реестр — `CONTENT-COVERAGE-AUDIT-2027.json`.
