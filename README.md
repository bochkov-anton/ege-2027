# ЕГЭ-2027 — локальный планировщик для 11 класса

**Готовое приложение:** HTML, CSS и JavaScript без сервера, аккаунтов, платных сервисов и SEO. Для Android подготовлено устанавливаемое PWA с офлайн-кэшем. **Главный сценарий — ссылка HTTPS → установка из Chrome на Android-планшет**, а не запуск отдельного `index.html` из файлового менеджера. Публикация HTTPS-ссылки выполняется отдельно.

## Основное устройство: Android-планшет

Работающий сайт: **[bochkov-anton.github.io/ege-2027](https://bochkov-anton.github.io/ege-2027/)**. Репозиторий — **[bochkov-anton/ege-2027](https://github.com/bochkov-anton/ege-2027)**. Рекомендуемый хостинг — **GitHub Pages**: GitHub раздаёт код и обновления по HTTPS, а **все заметки, отметки и результаты остаются локально на планшете**. Дополнительная синхронизация и вход в GitHub для ученицы не нужны. [Пошаговая публикация](./GITHUB-PAGES.md). На планшете открыть опубликованный HTTPS-адрес в Chrome → меню ⋮ → «Установить приложение».

## Быстрый запуск

В workspace CodexPro **learning** откройте папку **ege-2027-planner** и файл **index.html**. Для работы по адресу `localhost` (если нужно):

```bash
python3 -m http.server 8765
```

Из папки проекта открыть `http://localhost:8765`.

## Как заниматься за 30 секунд

1. Откройте **«Сегодня» → «Начать»**. Вверху всегда показано следующее невыполненное занятие. Школьная нагрузка спрятана в раскрываемые настройки, чтобы не мешать.
2. В карточке две вкладки: **«Теория: Фоксфорд + учебник»** — короткое объяснение Фоксфорда, систематическая теория по углублённому учебнику, краткий офлайн-конспект; **«Задания и проверка»** — индивидуальные упражнения с прямыми ссылками на РЕШУ ЕГЭ. Для книги можно сохранить §/страницы своей редакции.
3. В поле **«Быстрая запись»** оставьте только существенную заметку. Она сохраняется при вводе; таймер тоже сохраняет прошедшее время.
4. После практики введите **«8/10»** (если был набор из 10 задач), при необходимости укажите тип ошибки, затем нажмите **«Завершить занятие»**.
5. В «Повторениях» проверьте пару важных тем без подсказки и оцените результат. **Весь накопленный список за вечер делать не нужно.**
6. В разделе **«Предметы»** работает поиск по 234 темам (клавиша **/**), можно добавить **закладку**, личную ссылку и заметку к теме.
7. В **«Прогрессе»** доступны последние записи и результаты. **По пятницам** рекомендуется экспортировать JSON в «Настройки» — это единственная полноценная резервная копия без облака.

Если нет сил, выбирайте 35 или 90 минут либо отдых. Ручной режим не обходит защиту сна и ДЗ. Невыполненные обязательные темы сохраняются в очереди без переноса на выходные.

## Как устроен план

Стартовые условия: ученица 11 класса, после школы дома ориентировочно с 14:00. **Приоритет — школьное Д/З, сон 8–10 часов, еда и восстановление.**

- Базовый учебный день: **160 мин ЕГЭ** (55 + 50 + 45 + 10), с перерывами, плюс отдельное школьное Д/З.
- Облегчённый: **90 мин ЕГЭ**. Минимальный: **35 мин ЕГЭ**; при недосыпе, высокой нагрузке или позднем времени — **0 мин**.
- Полный отдых: **0 мин ЕГЭ**.
- Суббота и воскресенье полностью свободны.
- Учитываются **время подъёма, время окончания школы, дорога, школьное ДЗ, отдельные перерывы во время ДЗ, еда, восстановление, запас движения, сон прошлой ночи, желаемый сон и текущее время суток**. Ручное увеличение сверх предела запрещено. Это планировщик, не медицинская диагностика.
- 26 учебных недель, после них поддержание до фактических экзаменов.
- Два предмета в день; по вторникам математика получает длинное занятие. Чередование A/B.
- Повторы после изучения, оценка уверенности, ошибки, результаты задач **8/10**, ссылки по конкретным темам, экспорт/импорт JSON.
- Программа реагирует на нагрузку, не удваивает часы из-за пропущенного дня и ничего не переносит на выходные.
- **Очередь обязательных незавершённых блоков** сохраняется по порядку: прошедший понедельник не исчезает в четверг. Карточки ограничены дневным бюджетом, а назначенный состав дня не меняется после одной галочки.
- Таймер занятия продолжает отсчёт при закрытии карточки и переходе между разделами: активная сессия закреплена в верхней панели, время хранится локально и восстанавливается после повторного запуска. По достижении лимита показывается перерыв на 15/35 минут, возможны уведомления Android. Если система полностью выгрузила PWA, гарантированный фоновый будильник отсутствует.
- Вместо общей кнопки **«Материалы»** разделены **теория и задания**. Теория опирается на статьи Фоксфорда, практика — на прямые подборки `/test?filter=all&category_id=N` РЕШУ ЕГЭ; ФИПИ используется для требований экзамена, не как теория. См. [архитектуру обучения](./LEARNING-QUALITY.md).
- Вкладка «Неделя» показывает **календарный ориентир**, вкладка «Сегодня» — реальные следующие шаги, в «Очереди» — все незакрытые блоки.

**Формальная нагрузка и медицинские основания:** [WELLBEING-POLICY.md](./WELLBEING-POLICY.md). Медицинские источники определяют рекомендации по сну и активности; пороги ДЗ, учебные интервалы и 160/90/35/0 минут — продуктовые правила, не медицинские нормы.

**Исследование и подробная методика:** [MASTER-PLAN-2027.md](./MASTER-PLAN-2027.md). Здесь расписаны школьный день, рекомендации по отдыху, когнитивные методы, 26-недельный маршрут, адаптация, проверенные ссылки и научные источники.

## Материалы

В `textbooks.js` собраны **основной и альтернативный учебник для всех 234 тем**: авторы, тематические ориентиры, сайт издателя и поисковые ссылки Яндекса. Подтверждённые учеником § и страницы хранятся только локально, см. [библиотеку учебников](./TEXTBOOK-SOURCES.md). В `lesson-content.js` описаны **234 индивидуальные учебные цели, навыки и критерии**. В `theory-core.js` находятся краткие объяснения и подтверждённые тематические статьи **Фоксфорда** (на текущем этапе 72/234 тем имеют соответствующую внешнюю статью). В `topic-practice.js` — **прямые наборы задач** РЕШУ ЕГЭ для всех 234 тем; 139 уникальных страниц ответили HTTP 200 при проверке. **ФИПИ не используется в качестве теоретического учебника.** До полноценного охвата Фоксфордом все темы имеют самостоятельный офлайн-конспект, но он не заменяет длинную статью.

Биология: полный приложенный план 26 недель. Математика: полный приложенный план 26 недель. Химия: **только приложенная часть 1/10**; после первых 4 недель — примерное распределение макроплана без притворства, что остальные 9 частей были предоставлены.

Изначально упоминались четыре предмета. Здесь включены только три приложенных плана. Четвёртый предмет нельзя бесконтрольно добавить поверх этого времени.

## Сохранение и приватность

Прогресс остаётся в `localStorage` этого браузера и адреса. Если откроете приложение через другой браузер, профиль, `file://` вместо `localhost` или другое устройство, данные могут не перенестись. Делайте резервную копию: **Настройки → Скачать JSON**, желательно каждую пятницу. Импорт JSON заменяет текущий прогресс по подтверждению.

## Проверка

```bash
node --test tests/*.test.mjs
```

Никаких зависимостей для запуска или проверки нет. Режим визуального скриншота Firefox в подключённом окружении нестабилен; автоматические тесты интерфейса не заменяют визуальную проверку в обычном браузере.

## Что намеренно не реализовано

Облачная синхронизация, AI-репетитор, автоматическая проверка развёрнутых ответов ЕГЭ, перенос всех 2027 задач в локальную базу, надёжный научный прогноз баллов. Срок полезной жизни проекта — несколько месяцев, поэтому простота важнее инфраструктуры.
